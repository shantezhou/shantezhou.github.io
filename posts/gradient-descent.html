Gradient descent, in brief

2026-08-22

Most of modern machine learning rests on a single move: if you want to make a number smaller, compute which direction increases it fastest and walk the other way. The number is a loss L(θ), the direction is its gradient, and the walk is gradient descent:

θt+1 = θt − η ∇L(θt)

Here θ is everything the model is allowed to change — for a neural network, millions or billions of weights — and η is the step size, usually called the learning rate. That one line, iterated, is the whole algorithm.

Why the gradient?

Among all directions you could step in, the gradient ∇L points where L increases fastest, so −∇L is locally the steepest way down. For a small enough step, first-order Taylor expansion guarantees the loss decreases: L(θ − η∇L) ≈ L(θ) − η‖∇L‖². The squared norm is never negative, so as long as the gradient is not zero and η is small, you go downhill.

In code the loop is almost embarrassingly short: 

def gradient_descent(grad, theta, lr=0.1, steps=100):
    for _ in range(steps):
        theta = theta - lr * grad(theta)
    return theta

# minimize f(x) = (x - 3)^2, so df/dx = 2(x - 3)
argmin = gradient_descent(lambda x: 2 * (x - 3), theta=0.0)
print(argmin)  # 2.99999… → 3

Run it and the loss falls fast at first, then flattens as the gradient shrinks near the minimum:

The learning rate is the whole game

Everything interesting about tuning gradient descent hides inside η. For a quadratic bowl there is even a sharp threshold: converge if η < 2/λmax, where λmax is the sharpest curvature of the bowl (the largest eigenvalue of the Hessian). In practice you feel the threshold empirically:

η what you see
too small loss creeps down; training takes forever
about right smooth, roughly exponential decrease
too large loss oscillates, or blows up to NaN

An aside: in deep learning you almost never take the true gradient. You estimate it from a mini-batch, and the noise turns out to be a feature — it can shake the iterate out of sharp, poorly generalizing minima.

Where the plain version struggles

  • Ill-conditioned curvature. When the loss surface is a long narrow valley, the safe step size for the steep direction is far too timid for the shallow one — you zigzag. Momentum and Adam exist largely to fix this.
  • Saddle points and plateaus. The gradient goes to zero at places that are not minima, and progress stalls.
  • Non-differentiable objectives. No gradient, no descent — you need subgradients, smoothing, or a different tool entirely.
